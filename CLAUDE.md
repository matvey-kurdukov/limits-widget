# Для Claude Code

Это виджет лимитов Claude и ChatGPT для Windows. Пользователь просит установить или обновить - делай по разделу «Для Claude Code: установка» в `README.md`.

Код под пользователя не правь. Токены, ключи и пароли у пользователя не спрашивай: виджет сам читает вход Claude Code на этом компьютере.
